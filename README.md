Air Pollution Analysis Dashboard (Excel)

This project is an interactive Excel dashboard to analyze air pollution data across Indian states. It showcases data visualization and analysis skills using dynamic charts and filters.

🔧 Tools Used
Microsoft Excel
Pivot Tables & Charts
Slicers
📈 Features
Filter by state and pollutant (CO, NH3, NO2, OZONE, PM10, PM2.5, SO2)
Dynamic charts (bar, line, column, area)
Easy comparison of pollution levels
🚀 How to Use
Open the Excel file
Use slicers to filter data
Explore insights from charts
📌 Key Insight

PM10 and PM2.5 contribute most to pollution in many states.
